# Andre-AI-IOS
Andre AI is a fully local, privacy-respecting AI chat client for iPad and Mac, built entirely with native Apple frameworks (SwiftUI, SwiftData, Keychain, PDFKit) — no third-party dependencies. Bring your own API key for any OpenAI-compatible provider (OpenAI, Google Gemini, local servers like Ollama or LM Studio, and more).

Features: persistent multi-conversation history with stable UUID identity, streaming responses, long-term memory with explicit user confirmation, automatic conversation titles, smart context management for long chats, photo and file attachments (with vision support), model reasoning/thinking display, adjustable reasoning effort for supported models, an in-app model browser, JSON export/import, and 6 built-in themes.
